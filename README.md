# NewsDigestly -話題のニュースをもっと身近に-

## きっかけ
- 個人的にニュースを読む習慣がない
- これから就活の面接や社会人になって異なる世代の方々との出会いがあることから，ニュースを読むきっかけを作りたい
- ニュースを読みやすくすることで読むきっかけにつながるのでは

## システム概要
- ニュースを読みやすく表示するシステム
- 一週間で話題になったニュースを振り返る形式
- 機能
    - 選択した週のニュースをのランキングトップ10を**短く簡単に視覚的に**表示
    - **短く**: ニュース記事の本文を要約して短くまとめた文章を生成
    - **簡単に**: ニュースを要約した文章からキーワードを抽出してキーワードの説明文をツールチップを用いて表示
    - **視覚的に**: 共起ネットワークを用いてニュースの情報を図で可視化
- 特徴
    - 毎週月曜日にテレ朝ニュースサイトからニュース週間ランキング上位10件を取得

### 要約モデルについて
- livedoorの3行要約データセットを利用(約7000件取得)
#### モデルの性能評価
- 事前学習モデル: sonoisa/t5-base-japanese
- 学習データ : テストデータ = 8 : 2
- 精度評価(ROUGE値，BERTScore)
    | | ROUGE-1 | ROUGE-2 | ROUGE-L | BERT-Score |
    | :--- | :--- | :--- | :--- | :--- |
    | **F1** | 0.66 | 0.44 | 0.47 | 0.74 |

## データの構成とディレクトリ構造

本システムは，以下のディレクトリ構造とデータファイルが配置されている前提で動作します．
（※実際のニュースデータ，抽出キーワード，およびKHCoderの出力画像は利用規約および容量の観点から非公開としています）

### ディレクトリ構造
```text
project_root/
  ├── livedoor_summary_model/  # 要約モデル構築用ディレクトリ
  │   ├── T5_model.ipynb         # T5モデルを用いた要約のファインチューニング
  │   ├── output.csv             # 推論結果 (カラム: 要約1, 要約2, 要約3, 本文, 要約)
  │   └── livedoor_scraping.csv  # 学習用データセット
  │
  ├── news_sites/              # ニュース取得・前処理用ディレクトリ
  │   ├── news_preprocessing.ipynb # 取得したニュースデータのクリーニング・形態素解析
  │   ├── news_YYYY-MM-DD_n.csv  # 日別のスクレイピング生データ 
  │   └── news.csv               # 前処理完了後の統合データ (※system/ に配置して使用)
  │
  ├── keyword_extraction/      # キーワード抽出用ディレクトリ
  │   ├── easy_pke.ipynb         # pkeを用いた要約文からの重要キーワード抽出
  │   └── keywords.csv           # 抽出したキーワードと解説辞書
  │
  ├── system/                  # StreamlitWebアプリ（本番環境）
  │   ├── News_Digestly.py       # 本システム（Streamlit起動ファイル）
  │   ├── news.csv               # news_sites/ からコピーしたアプリ表示用データ
  │   └── keywords.csv           # ツールチップ表示用のキーワード辞書
  │
  └── KHCoder_images/          # 共起ネットワーク図の保存先
      └── YYYY-MM-DD.png         # 日付ごとの共起ネットワーク画像
